# Quick start
First make sure Targets are turned off and Base station is turned off.
- Turn on the Base Station
- Open Wi-Fi settings on Phone and connect Wi-Fi to Base Station Access Point 'Active Target AP'
- Open browser and go to the IP address displayed in the base station for example: 'http://10.1.1.0'
- Turn on Targets one by one. Wait for message on target display that says connected to Base Station

- On the browser app tab "Test targets"
  - Press a target number, the on screen button starts flashing.
    Now check to see the the light of the corresponding target is also flashing.
    Tab the onscreen button again, both the button and target stop flashing.
- Start a exercise on the "Exercises" screen

# Exercises
## Sequential shots
In this mode you shoor your targets in sequence


### Getting started
You have only one target connected to the basestation:
    - Tap 'Sequential Mode' in exercise selection screen
    - Choose the number of virtual targets per round.
    - Choose number of rounds you wish the play
    - Tap start to start the exercise

You have more then one target connected:
    - Choose 'Sequential Mode' in game selection screen
    - The number of targets is displayed on screen
    - Select number of rounds you wish the play
    - Press start to start the exercise

### How to play rounds
1: Round timer starts with a single beep.
2: Shoot each target, shot time is recorded
3: After all (virtual) targets are hit the turn ends with two beeps.
4: Press Start for the next round
    OR
   Next round starts after <secondsBetweenRounds> seconds
5: Three beeps indicate end of excersice
