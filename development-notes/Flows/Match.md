# Match flow

## Before a match begins
Shooters are added to the match, 
Targets are added to the match
A stop plate is added to the match


## Rounds
A shooter starts the round on the beep (given by the Centeral Server)
  - Beep requires button on web interface.
    See there links for harware interface to buzzer.
    https://forums.raspberrypi.com/viewtopic.php?p=2186990#p2186990
    https://github.com/sombriks/node-libgpiod?tab=readme-ov-file
    https://github.com/iiot2k/gpiox/tree/main
A shooter does the course.
The round finishes when the 'Stop Plate' is shot
