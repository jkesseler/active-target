# Quick start
First make sure Targets are turned of and Base station is turned off.
- Turn on the Base Station,
- Turn on Targets one by one. Wait for message on target display that says connected to Base Station

- Open Wi-Fi settings on Phone and connect Wi-Fi to Base Station Access Point 'Active Target AP'
- Open browser and go to the IP address displayed in the base station for example: 'http://10.1.1.0'
- Go to Test Targets: Each target will flash a light 3 times, if not restart the target
- Go to game settings, enter the number of rounds you want to play.

(For multiple targets only)
- Base station will base the number of turns based on the number of targets you have.
- Select Sequential play or Random Order play.

## Sequential timed shots
If you wish to play with a single phisical target make sure only on target is turned on. You won't be able to
select the numbe of virtual targets if you have more then one phisical target connected.

- Open the app
- Select the number of virtual targets per round, only possible of only possible if only one target is turned on.
- Select number of rounds you wish the play
- Press start to start the exercise

### How to play rounds
1: Round timer starts with a single beep.
2: Shoot each target, shot time is recorded
3: After all (virtual) targets are hit the turn ends with two beeps.
4: Press Start for the next round
    OR
   Next round starts after <secondsBetweenRounds> seconds
